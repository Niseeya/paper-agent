# 预置论文更新流程

面向仓库根目录 `论文/`：新增、替换 PDF 后，如何增量进入公用知识库并可被检索。  
**不要**手工把 PDF 拷进数据库；一律走本流程脚本。

相关配置：`deploy/corpus.yaml`  
相关脚本：`scripts/sync_corpus.py`、`scripts/import_corpus_to_db.py`、`scripts/embed_corpus.py`

---

## 1. 放文件

1. 将 PDF 放入 `论文/`（可建子目录，脚本会递归扫描 `*.pdf`）。
2. 单文件建议 ≤ 30 MB；文本型 PDF 优先（扫描件需 OCR，当前默认流程不保证过关）。
3. 命名建议：`题名_作者.pdf`，便于题名/作者回填。
4. 预置包应有来源与授权记录；无授权记录的不要导入。

替换已有论文时：用**新内容覆盖同名或新文件均可**。脚本按 **sha256** 判断是否已入库——内容变了就会当作新文件处理；若只要强制重解析，用下文 `--reparse`。

## 2. 环境准备（每次开新终端）

```bash
cd /path/to/论文智能体
source /opt/anaconda3/etc/profile.d/conda.sh
conda activate paperAgent

# 本机 Postgres（默认 5433）
bash scripts/pg_local.sh start
export DATABASE_URL=postgresql+psycopg://paper_agent@localhost:5433/paper_agent
export JWT_SECRET=dev-change-me

# 本地嵌入 / 重排（模型已缓存时可保持 offline）
export EMBEDDING_BACKEND=local
export EMBEDDING_LOCAL_MODEL=BAAI/bge-m3
export EMBEDDING_LOCAL_FILES_ONLY=1
export RERANKER_BACKEND=local
export RERANKER_LOCAL_MODEL=BAAI/bge-reranker-base
export RERANKER_LOCAL_FILES_ONLY=1
```

首次拉模型（无缓存时）可临时：

```bash
export HF_ENDPOINT=https://hf-mirror.com
export https_proxy=http://127.0.0.1:7890
unset EMBEDDING_LOCAL_FILES_ONLY RERANKER_LOCAL_FILES_ONLY HF_HUB_OFFLINE TRANSFORMERS_OFFLINE
```

## 3. 标准增量更新（最常用）

按顺序执行三步。

### 步骤 A：解析与切片（文件态）

先看将要处理什么（不写盘）：

```bash
python scripts/sync_corpus.py --papers-dir 论文 --dry-run
```

正式同步（按 sha256 **跳过已入库**，只处理新文件）：

```bash
python scripts/sync_corpus.py --papers-dir 论文 --config deploy/corpus.yaml
```

产物：

| 路径 | 含义 |
| --- | --- |
| `data/storage/papers/<paper_id>/source.pdf` | 落盘副本 |
| `data/storage/papers/<paper_id>/meta.json` | 题名、作者、年份、章节等 |
| `data/storage/papers/<paper_id>/chunks.json` | 文本切片 |
| `data/corpus_state/manifest.json` | 已索引清单 |
| `data/corpus_state/last_sync_report.json` | 最近一次报告 |
| `data/corpus_state/failed.jsonl` | 失败记录（不阻塞其他文件） |

终端会看到类似：`indexed=… skipped=… failed=…`。

### 步骤 B：写入正式库（Postgres）

```bash
python scripts/import_corpus_to_db.py
```

把 `data/storage/papers/*/meta.json` 与 `chunks.json` 写入表：`papers`、`document_files`、`knowledge_chunks`。  
已是 `indexed` 的 paper_id 会跳过。

### 步骤 C：向量化（pgvector）

```bash
python scripts/embed_corpus.py
```

只为**尚无当前模型向量**的切片生成嵌入，写入 `chunk_embeddings.vector`（`vector(1024)` + HNSW）。  
试跑可加：`--limit 20 --batch-size 4`。

若早期曾用 JSON 存向量、尚未迁到 pgvector：

```bash
python scripts/migrate_embeddings_to_pgvector.py
```

## 4. 更新后怎么验收

```bash
# 库内论文数 / 向量数（示例）
python - <<'PY'
from sqlalchemy import select, func
from backend.app.db import SessionLocal
from backend.app.models import Paper
from backend.app.models.embedding import ChunkEmbedding
db = SessionLocal()
print("papers", db.scalar(select(func.count()).select_from(Paper)))
print("embeddings", db.scalar(select(func.count()).select_from(ChunkEmbedding)))
db.close()
PY

# 混合检索冒烟
python - <<'PY'
from backend.app.skills.s2_retrieve import run_s2
r = run_s2({"query": "你的主题关键词", "mode": "hybrid", "top_k": 5})
print(r.status, r.error)
print(r.data.get("retrieval_meta"))
for p in (r.data or {}).get("papers", []):
    print("-", p["title"], p.get("year"), "p.", p.get("page_start"))
PY
```

也可用 Web：登录 → 项目 → 检索（混合模式），或 API：

`POST /api/v1/projects/{id}/retrievals`

## 5. 特殊情况

### 5.1 强制重解析（内容改了或解析要重做）

```bash
# 指定文件
python scripts/sync_corpus.py --papers-dir 论文 --reparse 论文/某篇_作者.pdf

# 全部重解析（慎用）
python scripts/sync_corpus.py --papers-dir 论文 --reparse
```

然后**必须再跑** B、C：

```bash
python scripts/import_corpus_to_db.py
python scripts/embed_corpus.py --force   # 同模型覆盖旧向量
```

### 5.2 只补向量（库里已有切片）

```bash
python scripts/embed_corpus.py
```

### 5.3 解析失败

查看 `data/corpus_state/failed.jsonl`。常见原因：加密 PDF、无可提取文本（扫描件）、损坏文件。  
失败条目不进入「已索引」，不能被 S2 检索；修好文件后重新执行步骤 A→C。

### 5.4 重复文件

sha256 相同会跳过，不建第二份索引。题名+第一作者高度一致时的业务去重，以入库/上传接口规则为准。

### 5.5 更换嵌入模型

旧向量与新模型**不得混检**。更换 `EMBEDDING_LOCAL_MODEL` / `EMBEDDING_MODEL` 后：

```bash
python scripts/embed_corpus.py --force
```

界面或调用方应提示重建索引；检索只使用当前 `model_id` 下的向量。

## 7. 流程关系（简图）

```text
论文/*.pdf
    │
    ▼  sync_corpus.py          （哈希去重 → 解析 → 切片 → 文件态 indexed）
data/storage/papers/<id>/
    │
    ▼  import_corpus_to_db.py  （写入 Postgres 元数据 + 切片）
papers / knowledge_chunks
    │
    ▼  embed_corpus.py         （bge-m3 → pgvector）
chunk_embeddings.vector
    │
    ▼  S2 混合检索（关键词 + 向量 + Reranker）
```

用户通过 Web「公用知识库」上传的 PDF 走上传接口，最终进入**同一公用库**；预置包仍以本文件的脚本流程为准。
