# 演示录屏

| 文件 | 说明 |
| --- | --- |
| `论文智能体_Web主路径演示.mp4` | Web 端主路径演示（约 2.5 分钟，推荐提交/播放） |
| `论文智能体_Web主路径演示.webm` | 同内容原始录制文件 |

## 内容顺序

1. 登录页  
2. 我的项目  
3. 公用知识库  
4. 项目概览与流程导航  
5. 文献检索（S2）及结果证据  
6. 大纲确认（S7）  
7. 章节写作（S8）  
8. 润色（polish）  
9. 引用核查（S9）  
10. 导出（S10）  
11. 独立研究工具（对比 / 研究空白）

每步顶部有深绿标题条说明当前功能；检索与核查等步骤有额外等待，便于看清结果。

## 如何播放

- **推荐**：用 Chrome / Edge 直接打开 `.webm`，或拖进浏览器标签页。  
- macOS「快速查看」/ 部分播放器可能不支持 VP9；若需 MP4，本机安装 ffmpeg 后执行：

```bash
ffmpeg -y -i "论文智能体_Web主路径演示.webm" -c:v libx264 -pix_fmt yuv420p "论文智能体_Web主路径演示.mp4"
```

## 重新录制

需本机 Web（5173）与 API（8000）已启动：

```bash
cd 论文智能体
node scripts/record_web_demo.mjs
```

脚本会写入本目录。旁白口播需另行人工配音（本文件为无旁白画面演示）。
