# 部署与运行说明（答辩演示版）

完整细节见 [`../../deploy/README.md`](../../deploy/README.md) 与 [`../预置论文更新流程.md`](../预置论文更新流程.md)。本文给出验收演示最短路径。

## 1. 环境

- conda 环境：`paperAgent`（Python 3.12）  
- 本机 PostgreSQL（默认端口 **5433**）+ pgvector  
- Node.js（Web / 移动端前端）  
- 可选：微信开发者工具（小程序）

```bash
cd 论文智能体
cp .env.example .env   # 勿提交真实 Key
source /opt/anaconda3/etc/profile.d/conda.sh
conda activate paperAgent
```

## 2. 数据库与初始化

```bash
bash scripts/pg_local.sh start
export DATABASE_URL=postgresql+psycopg://paper_agent@localhost:5433/paper_agent
export JWT_SECRET=dev-change-me
python -c "from backend.app.db import init_db; init_db()"
```

## 3. 预置论文入库（若库已就绪可跳过）

```bash
python scripts/sync_corpus.py --papers-dir 论文 --config deploy/corpus.yaml
python scripts/import_corpus_to_db.py
# 向量化（混合检索需要）
export EMBEDDING_BACKEND=local EMBEDDING_LOCAL_MODEL=BAAI/bge-m3 EMBEDDING_LOCAL_FILES_ONLY=1
python scripts/embed_corpus.py
```

## 4. 启动 API

```bash
export DATABASE_URL=postgresql+psycopg://paper_agent@localhost:5433/paper_agent
export JWT_SECRET=dev-change-me
export EMBEDDING_BACKEND=local EMBEDDING_LOCAL_MODEL=BAAI/bge-m3 EMBEDDING_LOCAL_FILES_ONLY=1
export RERANKER_BACKEND=local RERANKER_LOCAL_MODEL=BAAI/bge-reranker-base RERANKER_LOCAL_FILES_ONLY=1
uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```

健康检查：`http://127.0.0.1:8000/api/v1/health`  
OpenAPI：`http://127.0.0.1:8000/docs`

对话模型可在管理后台配置；首次也可在 `.env` 写 `LLM_*` 作为种子。

## 5. 启动客户端

```bash
# Web
cd frontend/web && npm install && npm run dev
# → http://127.0.0.1:5173

# Android 联调（Taro H5）
cd frontend/mobile && npm install && npm run dev:h5
# → 默认 http://127.0.0.1:10086 ；Android WebView 指向该 H5 或打包地址

# 微信小程序
cd frontend/mobile && npm run dev:weapp
# 开发者工具打开 frontend/mobile/dist
```

## 6. 演示账号

见根目录 README：`demo_tester` / `Demo1234`；`admin` / `Admin1234`。

## 7. Skill 独立测试（验收前建议执行）

```bash
conda activate paperAgent
export DATABASE_URL=postgresql+psycopg://paper_agent@localhost:5433/paper_agent
python -m pytest backend/tests/skills/ -q
```

## 8. Docker（可选）

```bash
docker compose -f deploy/docker-compose.yml up -d
```

端口与账号以 `deploy/docker-compose.yml`、`.env.example` 为准。
