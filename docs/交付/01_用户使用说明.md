## 2. 主路径（成稿）

```text
登录 → 创建项目 → 知识库检索 / 上传 PDF
  → 生成大纲并确认 → 按节写作 → 润色确认
  → 引用核查（L1/L2）→ 草稿导出 或 定稿导出
```

### 2.1 创建项目

进入「我的项目」→ 新建 → 填写题目 → 选择类型（综述 / 实证研究 / 设计与实现）。

### 2.2 知识库与检索

- **公用知识库**：浏览已索引论文；可按研究方向筛选；可上传 PDF（须勾选「我有权上传，并同意进入公用知识库」）。  
- **项目检索**：在项目内输入中/英文关键词，查看证据片段与来源（题名、作者、年份、页码）。  
- **备选篮**：在知识库或检索结果「加入备选」，供对比 / 研究空白使用（最多 8 篇）。

### 2.3 大纲（S7）

填写研究目标 → 生成大纲 → **必须点「确认大纲」**后才能批量按节写作。未确认时仅允许试写思路，不能定稿。

### 2.4 写作（S8）

大纲确认后：按节生成，或「生成缺失章节 / 重写全文」。正式引用必须能回链公用库已索引论文；无证据句会标为「无证据草稿」。

### 2.5 润色（polish）

选择轻度 / 学术 / 深度 → 对照原文确认后才写入正文。  
**不改**数字、专有名词、引用编号与结论方向。  
若请求「降重 / 规避查重」，系统**拒绝**并保持原文。

### 2.6 引用核查（S9）

运行核查：列出未通过 L1/L2 的句子及逻辑问题（重复、缺论据等）。  
定稿导出前须全部正式引用通过。

### 2.7 导出（S10）

- **草稿**：可导出，文首/页眉标明辅助生成草稿。  
- **定稿**：引用闸门未通过则拒绝，并提示回到核查。  
- 打开生成的 DOCX / PDF，确认非空、可阅读。

## 3. 独立研究工具（非成稿主链）

| 能力 | 入口 | 用法 |
| --- | --- | --- |
| 多篇对比（S4） | Web「研究工具」或移动端「分析」 | 备选篮 ≥2 篇 → 多篇对比 |
| 研究空白（S6） | 同上 | 填写研究现状（可含「不足/空白」）→ 可选附带备选论文 → 生成建议空白 |
| 方向分类 / 筛选（S5） | 公用知识库 | 按研究方向筛选文献 |

说明：对比与研究空白**不替代**大纲确认与引用核查；空白条目类型为「建议」，须看证据状态。

## 4. 管理员（仅 Web）

使用 `admin` 登录后打开 `/admin`：

1. 对话模型 Endpoint / 模型名 / API Key、连通测试  
2. 大纲 / 写作 / 润色提示词版本  
3. 查看并删除任意用户项目（只删文稿，不删已入公用库的论文）

---

## 5. 重要约束（请务必遵守）

1. 正式引用只能指向公用库中状态为「已索引」的论文。  
2. L1：题名/作者/年份与库内一致；L2：句子绑定证据片段并带页码。  
3. 不支持：抓取知网/谷歌学术全文、跳过确认直接定稿、降重规避、代写交稿。  
4. 小程序上传受平台体积限制；超限请改用 Web 或 Android。

---

## 6. 常见问题

| 现象 | 处理 |
| --- | --- |
| 检索无结果 | 确认预置论文已 sync + import + embed；论文状态为已索引 |
| 无法批量写作 | 先确认大纲 |
| 定稿被拒 | 打开核查页处理问题句，或改导出草稿 |
| 润色被拒 | 去掉降重要求，改选学术润色 |
| 管理后台进不去 | 须使用管理员账号；普通用户无此入口 |
