## 封面（1）

- 题目：基于 RAG 与多 Skill 协同的学术论文研究与生成 AI 智能体系统的设计与实现  
- 学员 / 单位 / 日期

## 一、背景与目标（2～3）

1. **问题**：学术写作辅助易「幻觉引用」、缺少证据约束与闸门。  
2. **目标**：在公用知识库证据约束下，完成检索→大纲→写作→润色→核查→导出。  
3. **交付边界**：Web + Android + 微信小程序；不做知网抓取、不做降重代写、iOS 非最低交付。

## 二、总体架构（2）

1. 分层示意：客户端 → `/api/v1` → 服务 / 工作流状态机 → Skill（S1～S10）→ 适配器（LLM / Embedding / Reranker / PDF）→ PostgreSQL+pgvector。  
2. 关键点：主控是**有限状态机**，不是无终止多 Agent 闲聊；正式引用必须回链已索引论文。

## 三、RAG 与知识库（2）

1. 预置 `论文/` + 用户上传 → 解析切片 → bge-m3 向量 → 关键词+向量混合检索 → Reranker。  
2. 截图：知识库列表 / 检索证据片段（页码）。

## 四、Skill 与主路径（3～4）

1. 一页总表：S1～S10 + polish 职责（表格）。  
2. 主路径泳道图或步骤条：登录→项目→检索→大纲确认→写作→润色→核查→导出。  
3. **三处闸门**：大纲确认、润色确认、定稿引用闸门（L1/L2）。  
4. 截图组合：大纲确认页、写作带引用、核查未通过/通过、导出。

## 五、多端与独立工具（2）

1. Web / Android(H5) / 小程序同一套 API；管理端仅 Web。  
2. 独立工具：多篇对比（S4）、研究空白（S6）、方向筛选；说明「不替代主流程闸门」。截图：分析页 / 备选篮。
