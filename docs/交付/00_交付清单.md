## 最低验收路径（对照 AC-14）

Web / Android（Taro H5）/ 微信小程序各走通一次：

登录 → 创建项目 → S1 主题（可选）→ S2 检索开源 → S3 上传解析 → S4 对比 → S7 大纲确认 → S8 一节带真实引用 → S9 核查 → S10 打开 DOCX/PDF。

独立工具：研究空白（S6）、方向筛选（知识库）、润色（polish）。
